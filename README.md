# 💧 Alpha Agua Sustentable — aguas.com.mx

Sitio web oficial de **Alpha Agua Sustentable**, parte de **Grupo Requilibrium**: una empresa dedicada a sanar el agua de manera natural, respetuosa y pasiva, sin químicos y con un consumo mínimo de energía.

🌐 **Sitio en producción:** [https://www.aguas.com.mx](https://www.aguas.com.mx)

> *"Encontrando el re-equilibrio."*

---

## 📖 Acerca del proyecto

Este repositorio contiene el código fuente del sitio institucional de Alpha Agua Sustentable. El sitio presenta la filosofía, los servicios, los proyectos y los productos de la empresa, y permite a los visitantes ponerse en contacto para solicitar soluciones a la medida de sus necesidades.

### Áreas de especialización

- 💧 **Agua**
- ⚡ **Energía renovable**
- 🌱 **Sustentabilidad**
- 🧭 **Asesoría**
- 🛒 **Comercialización**

### Objetivos que impulsa

- Agua limpia, sana y accesible
- Energía limpia y accesible
- Vida balanceada en el mar y la tierra
- Acción climática
- Coexistencia sustentable

## 🚀 Instalación y uso local

1. Clona el repositorio:

   ```bash
   git clone https://github.com/<usuario>/<repositorio>.git
   cd <repositorio>
   ```

2. Abre `index.html` directamente en tu navegador, o sírvelo con un servidor local:

   ```bash
   # Con Python
   python -m http.server 8000

   # Con Node.js
   npx serve .
   ```

3. Visita `http://localhost:8000` en tu navegador.
